# IntervAI repository orientation

Read `PROJECT_GUIDE.md` before changing this project. It contains the product workflows, architecture, feature-to-file map, current UI/orb preferences, Windows CMD setup/start/stop instructions, configuration requirements, known limitations and source-derived inventories.

Verify the relevant source and tests before editing; older phase/blueprint documents describe some superseded choices. Preserve unrelated working-tree changes, private data, ownership/CSRF/consent checks, immutable evidence, durable jobs and sandbox isolation. Never include `.env` values, passwords, keys or private uploads in documentation or commits.

For frontend work, also follow `frontend/AGENTS.md` and read the relevant installed Next.js documentation. Update the project guide when changing setup, architecture or behaviour. Record what was actually verified rather than claiming complete correctness from partial checks.
